Cloud-based Resource Optimization System

Project Information:

  • System simulates an automated greenhouse with robots which irrigate and harvest existing crops, and handle battery charging.
  • System rules:
    • Crop moisture levels reduce and growth levels increase with each time step.
    • Robot battery levels reduce with each time step.
    • At specified thresholds, tasks for irrigation, harvesting, or charging are created in parallel.
    • When available, robots select the next task based on priority.

Currently Complete Features:

  • .NET backend with PostGreSQL database connectivity.
  • Task creation and selection all occurs in parallel, with robots selecting the next available highest-priority task.
  • Viewable local HTML dashboard with real-time updates.
  • Unit and in-memory database integration testing complete using xUnit framework.
  • Deployed the Dockerized application on AWS EC2, with Amazon RDS (PostgreSQL) for data persistence. (Previously completed: Git-based Docker deployment on Render.)

Features Currently Under Development:

  • Full integration, end to end, and concurrency testing.
